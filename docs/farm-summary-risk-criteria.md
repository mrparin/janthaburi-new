## 1) เกณฑ์ให้คะแนนความเสี่ยง (risk_score)

| หมวด | เงื่อนไข | คะแนนที่เพิ่ม | เหตุผลที่แสดง (reasons) | ข้อแนะนำที่แสดง (actions) |
|---|---|---:|---|---|
| VPD | `vpd_kpa > 1.8` | +2 | VPD ในสวนอยู่ในระดับวิกฤต | เพิ่มความชื้นในทรงพุ่มและตรวจรอบน้ำ |
| VPD | `1.4 < vpd_kpa <= 1.8` | +1 | VPD ในสวนค่อนข้างสูง | เฝ้าระวังการคายน้ำของต้น |
| อุณหภูมิพยากรณ์ 3 วัน | `max_temp_3d >= 35` | +2 | พยากรณ์อุณหภูมิสูงสุด 3 วันเกิน 35°C | เตรียมแผนให้น้ำช่วงเช้าตรู่และเย็น |
| อุณหภูมิพยากรณ์ 3 วัน | `33 <= max_temp_3d < 35` | +1 | พยากรณ์อุณหภูมิสูงสุด 3 วันค่อนข้างสูง | ติดตามอุณหภูมิทรงพุ่มอย่างใกล้ชิด |
| ฝนสะสมพยากรณ์ 3 วัน | `rain_3d >= 60` | +2 | พยากรณ์ฝนสะสม 3 วันสูง | ระบายน้ำโคนต้นและลดการให้น้ำ |
| ฝนสะสมพยากรณ์ 3 วัน | `25 <= rain_3d < 60` | +1 | พยากรณ์มีฝนต่อเนื่อง | ตรวจการระบายน้ำและโรคจากความชื้น |
| ความชื้นดิน | `soil_humi < 35` | +1 | ความชื้นดินปัจจุบันต่ำ | ตรวจระบบน้ำหยดและเพิ่มรอบน้ำอย่างเหมาะสม |
| ความชื้นดิน | `soil_humi > 80` | +1 | ความชื้นดินปัจจุบันสูงมาก | เฝ้าระวังน้ำขังและรากขาดอากาศ |

## 2) เกณฑ์แปลงคะแนนเป็นระดับความเสี่ยง

| risk_score รวม | risk_level | headline |
|---:|---|---|
| `>= 4` | `danger` | ความเสี่ยงสูง ควรจัดการทันที |
| `>= 2` และ `< 4` | `warning` | มีความเสี่ยงปานกลาง ควรเฝ้าระวัง |
| `< 2` | `normal` | สภาพรวมอยู่ในเกณฑ์ปกติ |

## 3) เงื่อนไข fallback

| กรณี | ข้อความที่ระบบใส่ให้ |
|---|---|
| ไม่มี reasons เลย | ค่าจากสถานีและพยากรณ์ยังไม่พบความเสี่ยงเด่น |
| ไม่มี actions เลย | รักษาแผนดูแลปัจจุบันและติดตามข้อมูลต่อเนื่อง |
